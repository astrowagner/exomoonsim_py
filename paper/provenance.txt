Provenance for the Paper III figures and tables
================================================
exomoonsim source   : github.com/astrowagner/exomoonsim_py
Python              : 3.10.12
numpy               : 2.2.6
matplotlib          : 3.10.9

These scripts live in the exomoonsim repository and import the package from the repo
root (one level up), so the figures are regenerated against the same source that is
version-controlled here -- no separate frozen copy. To reproduce a published figure at
a specific version, check out the corresponding commit/tag of this repository.

Fixed inputs (do not change if you want bit-for-bit reproduction):
  make_recovery_fig.py     seed=11, single 1 Mearth moon, 10 uas, 5 yr, circular
  make_two_moon_fig.py     seed=42, two moons (0.3/0.2 Mearth at 20/12 Rjup), 10 uas, 5 yr
  ../run_50muas.py         SurveyConfig default base_seed, 50 uas, 9x101 grid, 50 trials
  data/survey_50muas_ntrials50.npz   exact output of ../run_50muas.py
  data/idl_cubes_dump.txt  original IDL cubes (validation/dump_cubes.pro), matched grid
